# FL0027: Use a static import for `FormattableString.Invariant`

Repeated `FormattableString.Invariant(...)` calls are easier to read with a static import.

```csharp
using static System.FormattableString;

var text = Invariant($"text = ({value})");
```

The code fix replaces qualified calls to `System.FormattableString.Invariant` with `Invariant` and adds `using static System.FormattableString;` as the last top-level using if it is not already in scope. Calls already written as `Invariant(...)` are not reported.
